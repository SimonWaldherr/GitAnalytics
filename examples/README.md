# Beispiele

- `gitanalytics.example.json`: vollständige Ausgangskonfiguration mit Aliasbeispiel.
- `queries.sql`: SQL-Beispiele für die öffentliche SQLite-Datenbasis.
- `demo-report.html`: vollständig offline nutzbarer Bericht aus zwei synthetischen Test-Repositories. Die enthaltenen Namen, Adressen und Commit-Daten sind Testdaten.
